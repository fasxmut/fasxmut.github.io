Botan TLS

Botan Cryptographic Library

Botan is a c++ cryptographic library, it implemented TLS 1.1, TLS 1.2, and TLS 1.3 .

boost::asio interface.

boost::beast interface.

Botan TLS can be interactive with asio/beast directly.

TLS::Stream

Botan::TLS::Stream is a tls stream compatible with boost::asio .

It is a class template.

TLS::Stream has two template parameters: next layer type and channel type.

Next layer type can be set to boost::beast::tcp_stream, or any type that carries an asio socket.

Channel type deaults to TLS::Channel, channel type is for testing only.

TLS::Context

Botan::TLS::Context is a helper class to initialize and configure TLS::Stream.

TLS::Context main constructor has five parameters:

  • a credentials manager (c++ std::shared_ptr)
  • a botan rng (Random Number Generator) (c++ std::shared_ptr)
  • a session manager (c++ std::shared_ptr)
  • a tls policy (c++ std::shared_ptr)
  • a server information

Botan::Credentials_Manager

Botan::Credentials_Manager is a credentials manager class which can be used for both TLS server and client.

TLS::Session_Manager

Botan::TLS::Session_Manager is an interface to systems which can save session parameters for supporting session resumption.

Botan::RNG

Botan::RNG or Botan::RandomNumberGenerator

Botan::RandomNumberGenerator is an interface to a cryptographic random number generator.

There are some Botan RNGs that are derived from Botan::RandomNumberGenerator :

  • Botan::AutoSeeded_RNG
  • Botan::ChaCha_RNG
  • Botan::Jitter_RNG
  • Botan::HMAC_RNG
  • Botan::ESDM_RNG
  • Botan::System_RNG
  • Botan::Processor_RNG
  • Botan::Stateful_RNG
