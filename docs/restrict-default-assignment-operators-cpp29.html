Restrict default assignment operators, c++29

> Start
> Back: Home

Current c++ permits various ways of defaulted assignment operators of class.

Such as these permit implausible declarations:

A & operator=(const A &) && = default;

B & operator=(const B &) const = default;

Where A, B are c++ classes.

Proposed c++29 will forbit such declarations.
