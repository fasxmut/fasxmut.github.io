c++ is a high performance object-oriented programming language for both low-level programming and high-level applications.

Quickbook/Boostbook are document generator/writer written by c++ boost developers.

In this site, almost all docs have a quickbook document id, which is the same as the string that has removed the filename extension from its related qbk filename.

For example,

If the document is cpp-world.qbk, then the document id is cpp-world, and the related url ends with cpp-world.html
